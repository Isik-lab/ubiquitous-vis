# ubiquitous-vis
Code for the paper 'Ubiquitous cortical sensitivity to visual information during naturalistic, audiovisual movie viewing'. [Read the paper here!](https://osf.io/preprints/psyarxiv/b5p4n_v1)

## Setup
```
conda env create -f environment.yml
conda activate ubiquitous-vis
pip install -e .       
```

## In this repository
- **Second Level analysis results**: precomputed results from SecondLevel Analyses.ipynb, that are used by Plot Figures.ipynb to create the figures
- **Figures**: the figures generated by Plot Figures.ipynb and their source data
- **Code**: all code used for analyses in the paper

## In other places
- **First Level analysis outputs** (first-level GLMs and encoding models) are [on Hugging Face](https://huggingface.co/datasets/hsmall/sherlock-and-localizers-fMRI). Download them into the repository root (`huggingface-cli download hsmall/sherlock-and-localizers-fMRI --repo-type dataset --local-dir .`) to rerun the second-level analyses.
- **Raw and preprocessed fMRI**: raw fMRI (BIDS) and fMRIprep derivatives are [available on OpenNeuro](https://openneuro.org/datasets/ds006677).


## Repository layout
```
src/                         all analysis code 
scripts/
  Plot Figures.ipynb         makes every main and supplementary figure using precomputed subfigures within this repository
  SecondLevel Analyses.ipynb group and ROI analyses that produce the subfigures, can be run loading the precomputed results within this repository or from scratch with the data from hugging face
  config.sh                  paths and conda environment
  sbatch/                    one SLURM job script per first-level analysis step
  params/                    GLM contrasts and the feature-space pairs for the feature similarity analysis
analysis/                    (+ Hugging Face outputs once downloaded)
  participants*.tsv          participant lists (all 34; 25 with the language localizer)
  parcels/                   group-constrained parcels (MT, STS, language) and MNI templates
  FeatureSpaceCorrelation/   feature space similarity results
  SecondLevelIndividual/     precomputed ROI results (summaries, response similarity, speaking-only evaluation, overlap) (more on Hugging Face)
  SecondLevelGroup/          group maps needed for ROI analyses (more GLM and encoding model group maps on Hugging Face)
  PCInterpretation/          pooled PCA interpretation results
figures/                     subfigures and final figures
tables/                      supplementary tables
```


### running code
Plotting code for all main and supplemental figures is in ``` /scripts/Plot Figures.ipynb ```. This can be run if you clone this repository. All figures are created in ``` /figures ```. 

The second level analyses can be run in ``` /scripts/SecondLevel Analyses.ipynb ```. With `load=True`, the ROI analyses (Figures 3B, 4, 5 and Supplementary Figures 5–9) run from the precomputed results in this repository. To generate the brain maps and run everything from scratch you need data from [Hugging Face](https://huggingface.co/datasets/hsmall/sherlock-and-localizers-fMRI). The notebook contains details on which data to download for your specific needs!

See the sbatch scripts in ``` /scripts/sbatch ``` for preprocessing (fMRIprep) and running the first level analyses (edit ``` /scripts/config.sh ``` first). The encoding models took about 3 hours on an a100 gpu per subject when saving the fitted weights.
